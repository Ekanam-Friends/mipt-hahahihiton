# Запуск и настройка

[README](../README.md) · [Документация проекта](PROJECT.md)

Команды выполняются из корня репозитория. Ниже сохранены инструкции локального запуска; серверная конфигурация описана в [документации проекта](PROJECT.md#серверное-развёртывание).

## Веб-интерфейс и Docker (Е4)

Нужен Docker Desktop с Linux-контейнерами и Compose v2. Сборка скачивает Python, пакеты и Tesseract с `rus`/`eng`; работа с подготовленным корпусом в базовой конфигурации не требует интернета. Корпус и модель в образ не включаются. Предварительно получите `data/official/manifest.jsonl` и `data/official/raw/` по [E0](E0.md); текущий официальный снимок — от 11.11.2026. Базовый Compose явно выбирает `extractive`; модель подключается отдельной конфигурацией ниже.

```powershell
docker compose build
# Только если исходники ещё не импортированы; запись в корпус разрешена лишь этому одноразовому процессу:
docker compose run --rm -v ./data/official:/app/data/official:rw web python -m regnav --data data/official ingest --workers 2
docker compose up -d --wait
docker compose ps
```

Открыть [локальный интерфейс](http://127.0.0.1:8000). Выбрать вымышленный демо-аккаунт, открыть «ИИ-ассистент». Первый сценарий: «Как открыть финансовый лицевой счёт?» → краткие выдержки → раскрыть доказательство → «Точный фрагмент» → «Скачать оригинал». Второй: «Как открыть финансовый лицевой счёт и оформить внутреннее заимствование?» → проверить несколько документов. Затем задать уточнение; «Новый диалог» очищает историю. Вопрос «Как получить ипотеку на личную квартиру через Госуслуги?» проверяет отказ в пределах доступного снимка.

По умолчанию `extractive` возвращает выдержки со статусом **«Частичный ответ»**, а не полную сгенерированную процедуру. Для полного ответа запустите локальную модель по [E3](E3.md) и используйте локальный запуск FastAPI ниже. Контейнеру требуется ориентировочно 1–2 ГБ RAM без модели (не измеренный максимум); CPU-модель Qwen3-4B Q4_K_M с контекстом 12288 требует отдельного запаса памяти. Практический ориентир для всей системы — 12–16 ГБ RAM; на машине с 8 ГБ возможны длительная обработка и подкачка. Время CPU-ответа может измеряться минутами; таймаут по умолчанию 1800 с.

```powershell
# Логи и остановка (корпус и сессии сохраняются)
docker compose logs --tail 100 web
docker compose down
# Повторный запуск после изменения корпуса или конфигурации
docker compose up -d --force-recreate --wait
```

Веб-процесс читает корпус без права записи, сессии хранит в томе `web-state`, запускается без root, с одним worker. При пустом/повреждённом индексе `/api/health` возвращает 503; проверьте импорт и пересоздайте процесс. Статус Docker `healthy` подтверждает готовность индекса, а не качество/доступность модели. При TLS-сбое PyPI можно явно выбрать HTTPS-зеркало: `docker compose build --build-arg PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple`. Сертификаты проверяются.

### Локальный запуск FastAPI и модели

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-web.txt -c constraints-web.txt
$env:REGNAV_DATA='data/official'
$env:REGNAV_LOCAL_ONLY='1'
$env:REGNAV_LLM='extractive'
.venv\Scripts\python.exe -m uvicorn regnav.web.app:app --host 127.0.0.1 --port 8000 --workers 1
# Остановка: Ctrl+C
```

Для генерации сначала запустить `scripts/start_local_model.ps1` в другом терминале, затем перед запуском uvicorn задать `REGNAV_LLM=openai`, `OPENAI_BASE_URL=http://127.0.0.1:8087/v1`, `OPENAI_MODEL=regnav-local`, `OPENAI_API_KEY=EMPTY`, `REGNAV_LLM_TIMEOUT=1800`, `REGNAV_MAX_TOKENS=1800`. Сервис модели запускается и останавливается отдельно. Для модели на хосте из Docker предусмотрен явный вариант `docker compose -f compose.yaml -f compose.local-model.yaml up -d --wait`: он разрешает адрес `host.docker.internal:8087`. Сервер модели должен быть доступен контейнеру; стандартный скрипт с `127.0.0.1` такой доступ не гарантирует. Этот дополнительный вариант требует отдельной настройки сетевого доступа; локальный запуск обоих процессов обходится без неё.

### Данные и внешние обращения

`REGNAV_LOCAL_ONLY=1` по умолчанию запрещает внешние провайдеры. OpenAI-совместимый сервер допускается только по loopback IP или по явно указанному `REGNAV_LOCAL_MODEL_HOSTS` (список доверенных локальных узлов через запятую). В локальном режиме игнорируются proxy-переменные и не выполняются HTTP-перенаправления. Compose использует bridge-сеть для опубликованного локального порта; это не сетевая песочница. Запрет внешнего API реализован в приложении, а отсутствие попыток соединений в базовом сценарии проверяется тестом. Для изолированной проверки импорта используется контейнер с `--network none`. Для разрешённого внешнего API требуется явное `REGNAV_LOCAL_ONLY=0`; перед этим отдельно проверяют допуск каждого документа и вопроса. Профиль демо-пользователя модели не передаётся.

Сервисы: один FastAPI/SQLite; опционально отдельный локальный OpenAI-совместимый сервер. Внешние вызовы при установке: реестр Docker, Debian APT, PyPI (или явно выбранное зеркало), загрузчик официального корпуса, установщик модели. Во время базового веб-сценария внешних сервисов нет; JS/CSS локальные. Оригиналы доступны из локальной копии после входа. `.env` читает **Compose**; CLI и uvicorn требуют переменные окружения оболочки.

`REGNAV_WEB_TIMEOUT` задаёт ожидание ответа, `REGNAV_WEB_DB` — SQLite, `REGNAV_PORT` — порт Compose. Сервер ограничивает вопрос 8000 символами и историю шестью репликами. История находится только в памяти вкладки. Одновременно выполняется один запрос: после таймаута Python-поток заканчивает работу, слот остаётся занят и возвращает 429; это предотвращает накопление задач. Вход без пароля разрешён только двум вымышленным демо-профилям; перед публичной эксплуатацией нужна полноценная аутентификация. Полный перенос кабинетов MGIMO-LMS — [отдельная задача](cabinets-backlog.md).

Проверки: `.venv\Scripts\python.exe -m pytest tests/test_web.py tests/test_e4.py -q`, `node --check regnav/web/static/app.js`. Необязательный браузерный smoke-test с установленными Chrome и Playwright: `.venv\Scripts\python.exe -X utf8 scripts/verify_e4_browser.py --url http://127.0.0.1:8000`. Доказательства и границы приёмки — [E4](E4.md).

## Запуск существующего CLI

Требования: Python 3.10+, зависимости из `requirements.txt`. Для сканов нужны Tesseract OCR и русские языковые данные. Команды выполняются из корня репозитория; далее предполагается доступный `python` (на Windows можно использовать `py -3.10`).

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:REGNAV_LLM = "extractive"
python -m regnav --help
python scripts/download_official.py
python -m regnav --data data/official ingest --workers 2
python scripts/verify_e1.py
python -m regnav --data data/official search "Как оформить командировку?" -k 5
python -m regnav --data data/official ask "Как оформить командировку?" --json
python -m pytest -q
```

Для Linux/macOS активация: `source .venv/bin/activate`, переменные задаются через `export`. Перед ingest подготовить `manifest.jsonl` и исходники по `local_path`; один JSON-объект на строку, поля: `id`, `title`, `local_path`, `url`, `doc_type`, `uploaded_at`, `source`. Использовать отдельный каталог, например `data/official`, для официального корпуса. Загрузчик официальной папки: `scripts/download_official.py`; запуск описан в [E0](E0.md). Без манифеста и файлов команды поиска не дают содержательного результата. После изменения корпуса повторить ingest; для обновления кэша извлечения использовать `--force`.

Для генерации с локальной Qwen3-4B-Instruct-2507 выполните `scripts/setup_local_model.ps1`, затем `scripts/start_local_model.ps1` в отдельном терминале и задайте переменные из `.env.example` (включая таймаут 1800 с для длинных процедур на CPU). Профиль использует контекст 12288 токенов. По умолчанию сервер слушает только `127.0.0.1:8087`; остановка — Ctrl+C. Установка закрепляет версии и проверяет SHA-256. Полные команды и ограничения памяти — в [E3](E3.md).

CLI завершается после команды, прерывание — Ctrl+C. Ошибка ответа возвращает код 1; `partial`, `clarify` и `not_found` — отдельные содержательные состояния, а не технический сбой. Команды Docker приведены выше.

### Настройки и внешние сервисы

| Переменная | Значение и назначение |
|---|---|
| `REGNAV_LLM` | `extractive` по умолчанию — без вызовов LLM; `gigachat` или `openai` включают API |
| `TESSERACT_DIR` | Каталог Tesseract; Windows default: `C:\Program Files\Tesseract-OCR` |
| `TESSDATA_DIR` | Языковые данные OCR; default: `.tessdata`, нужен `rus.traineddata` |
| `GIGACHAT_AUTH_KEY` | Ключ GigaChat, только для `gigachat` |
| `GIGACHAT_SCOPE` / `GIGACHAT_MODEL` | Defaults: `GIGACHAT_API_PERS` / `GigaChat` |
| `GIGACHAT_CA_BUNDLE` | Путь к доверенным CA, если необходим |
| `OPENAI_BASE_URL` | Адрес OpenAI-совместимого API, обязателен для `openai` |
| `OPENAI_API_KEY` | Ключ сервера; default `EMPTY` для локального сервера |
| `OPENAI_MODEL` | ID модели; default `ai-sage/GigaChat-20B-A3B-instruct`; для локальной модели `regnav-local` |
| `REGNAV_LLM_TIMEOUT` | Таймаут OpenAI-совместимого сервера, default 600 с для медленного локального CPU |
| `REGNAV_MAX_TOKENS` | Лимит генерации OpenAI-совместимого сервера, default 1800 |

Внешние сервисы опциональны: GigaChat OAuth/API либо сервер по `OPENAI_BASE_URL`. Последний может быть локальным. Поиск и режим `extractive` не требуют API модели. `.env` автоматически не загружается: задавайте переменные окружения до запуска. Не сохраняйте ключи в Git.
