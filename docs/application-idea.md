# Текст для поля «Идея решения» в командной заявке

RAG-ассистент по регламентам и приказам МФТИ. Он отвечает не пересказом документа, а
пошаговым чек-листом: что сделать, кто отвечает, в какой срок, какая форма нужна. У каждого
шага есть ссылка на пункт документа и дословная цитата. Шаги без подтверждения отбрасываются.
Если подходящего регламента в базе нет, система честно об этом говорит. Учитываем редакции:
приказы, которые изменяют или отменяют документ, и противоречия между документами. Если
порядок зависит от роли сотрудника, задаём уточняющий вопрос. Поиск гибридный (по словам и
по смыслу), документы режем по их структуре на пункты. Интерфейс — веб-чат с просмотром
цитируемого пункта. LLM подключается через адаптер: для демо GigaChat или YandexGPT, но её
можно заменить открытой моделью внутри контура МФТИ, чтобы документы не покидали периметр.
