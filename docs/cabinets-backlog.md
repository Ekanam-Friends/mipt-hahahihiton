# Кабинет MGIMO-LMS: объём и состояние

## Уточнение пользователя 14.11.2026

Нужен привычный кабинет сотрудника по структуре и оформлению MGIMO-LMS с упрощённым входом. ИИ-ассистент находится в «Сервисах» и открывается круглой кнопкой справа снизу. Нереализованные разделы сохраняются в навигации и показывают «Раздел недоступен в рамках хакатона». Их полноценная реализация не требуется для этого интерфейса.

## Реализовано локально 14.11.2026

- Стили оболочки перенесены из `MGIMO-LMS/app/web/static/app.css` в `regnav/web/static/cabinet.css`: меню, шапка, плитки, профиль, адаптивность и нижняя мобильная навигация. Шрифты и скрипты извне не загружаются; используется системный шрифт с локальным Manrope при наличии.
- Главная: информационная лента с отметкой недоступности, мои сервисы, ресурсы университета, кадровая служба; у преподавателя также блок рабочих разделов.
- Меню сотрудника/преподавателя, раскрываемые кадровые разделы, профиль, сервисы, переходы через URL hash.
- Общий диалог для полной страницы и виджета: сохраняются черновик, дата, ответы и история при переходах. Закрытие по кнопке/Escape; разворачивание на страницу. После выхода диалог очищается. После обновления страницы диалог не сохраняется.
- Прежние API, локальный режим и проверка источников сохранены.

Проверки: 14 HTTP/приватность-тестов; `node --check`; Chrome — реальный extractive-ответ, якорь и скачивание оригинала, повтор вопроса после ошибки, оба профиля и 360 px. Дополнительная проверка общего диалога использует явно имитированный ответ, без заявления о новой приёмке качества LLM. Отчёты и скриншоты: `data/official/cabinet-checks/`; команды: `scripts/verify_e4_browser.py`, `scripts/verify_cabinet_browser.py` (порт 8020). Первая версия дополнительного теста ошибочно закрывала уже раскрытое кадровое меню; тест исправлен, итоговый прогон пройден.

Figma: обновление запрошено, ожидается ссылка пользователя на целевой файл. Код и макет автоматически не синхронизируются.

## Расписание преподавателя — заглушка 14.11.2026

По запросу пользователя раздел «Расписание» показывает пример недели с вымышленными занятиями, группами и аудиториями. Лекции, семинары и консультация выделены цветом, суббота — без занятий. Данные явно помечены демонстрационными; реальная интеграция не реализована. Доступ — меню преподавателя, плитка главной и мобильная нижняя панель. На главной также показан сам блок расписания: два занятия примерного понедельника и переход «Вся неделя». Данные карточек общие с недельным расписанием; пример дня не выдаётся за занятия на текущую дату.

## Отдельный будущий объём

Следующие функции не объявляются работающими в хакатонном кабинете:

- Курсы, ведомости, задания, расписание, объявления с редактированием и проверкой владельца.
- Кадровые действия, интеграции с внешними системами, содержательные данные и миграции.
- Промышленная аутентификация и постоянное хранение диалогов.

Не импортировать реальные профили или БД MGIMO-LMS без отдельного согласования.
